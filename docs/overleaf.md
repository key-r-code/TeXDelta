# Overleaf

`texdelta init-overleaf DEST` creates a self-contained project with a Python zipapp, `latexmkrc`, a driver document, and fixed `Old/` and `New/` folders.

1. Run the command locally and upload the resulting directory as a new Overleaf project.
2. Replace the contents of `Old/` and `New/` while retaining `main.tex` as each entry point.
3. Set the project compiler to pdfLaTeX and recompile.

The custom `latexmkrc` runs the bundled zipapp before compiling the generated `texdelta-output/diff.tex`. Report-based dependency caching prevents a repeated latexmk build loop and causes regeneration when tracked inputs change.

Overleaf must provide Python 3, pdfLaTeX, BibTeX, Perl, latexpand, and latexdiff. The runner does not download or install tools. Projects requiring shell escape, Biber, XeLaTeX, or LuaLaTeX are outside the source-preview scope.

The committed runner is generated by `python tools/build_overleaf_runner.py`. CI rebuilds it and fails if the committed artifact drifts from the Python core.
