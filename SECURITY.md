# Security Policy

## Supported versions

Only the latest source-preview revision is supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a suspected vulnerability and do not include confidential documents in a report.

TeXDelta processes trusted local LaTeX projects. It reduces accidental exposure through isolated staging, root-boundary checks, and disabled shell escape, but it is not a sandbox for hostile TeX input.
